# Code availability

The code and supporting files for the [interactive visualisation](https://meiziyou-research.github.io/Heat-Perception-2/) are included in this repository: [`index.html`](index.html) and the [`webpage/`](webpage/) scripts, styles, data files and assets. The classification [codebook](codebook/) and evaluated [prompt variants](prompts/) are also available here.

The [figure Source Data workbook](source_data/Source_Data_NCC_Figures.xlsx) contains numerical values underlying the main and Extended Data figures, but is not itself executable analysis code. The repository does not currently include the restricted post-level corpus or a complete runnable pipeline for every statistical analysis. The methods, model definitions and data-access limitations are reported in the article and its Supplementary Information. See [Data Availability](DATA_AVAILABILITY.md) for data sources and restrictions.
