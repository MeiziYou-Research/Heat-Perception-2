# Code availability

The code and supporting files for the [interactive visualisation](https://meiziyou-research.github.io/Heat-Perception-2/) are included in this repository: [`index.html`](index.html) and the [`webpage/`](webpage/) scripts, styles, data files and assets. The classification [codebook](codebook/) and evaluated [prompt variants](prompts/) are also available here.

Numerical figure data are available in the [Source Data workbook](source_data/Source_Data_NCC_Figures.xlsx). Data sources and access conditions are described in [Data Availability](DATA_AVAILABILITY.md).
