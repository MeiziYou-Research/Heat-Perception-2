# Validation summaries

`overall_validation_metrics.csv` contains the saved five-model emotion and attention accuracy, Cohen's kappa, and effective evaluation n used for Extended Data Fig. 7. Gemini attention has n = 795; the other model-task combinations have n = 800.
The saved file abbreviates Claude Sonnet 4.5 as `Claude` and Gemini 2.5 Flash as `Gemini`; the figure displays the full names.

`country_stratified_metrics.csv` records the author-confirmed four-country summary used for Supplementary Fig. 17. Country sample sizes total 800 posts. Percentages and kappa values are reproduced from the confirmed summary; this file does not contain individual predictions or post text.

These summaries are descriptive validation results, not a replacement for the restricted post-level validation data.
