# Codebook

This folder contains the codebook materials used for closed-set LLM annotation of urban heat perception.

## Files

- `codebook_full_attention_emotion.txt`: complete plain-text coding manual.
- `Extended_Data_Table_1_attention_taxonomy.csv`: the 24-row attention taxonomy exported from the final manuscript's Extended Data Table 1.
- `attention_taxonomy_detailed.csv`: additional theoretical and coding context retained from the earlier structured codebook; not a substitute for Extended Data Table 1.
- `Extended_Data_Table_2_emotion_scheme.csv`: structured emotion scheme with seven labels, corresponding to Extended Data Table 2.

The plain-text codebook consolidates the annotator role, task scope, in-scope and out-of-scope criteria, single-label decision rules, attention definitions, emotion definitions, output schema and quality-control checklist.
