# Figure source data

[`Source_Data_NCC_Figures.xlsx`](Source_Data_NCC_Figures.xlsx) is the consolidated numerical source-data workbook for main Figs. 2–6 and Extended Data Figs. 1–7. Each figure or panel has its own worksheet. Main Fig. 1 is a conceptual illustration and has no numerical sheet.

The workbook supersedes the five earlier split files named `Source Data Fig. 2.xlsx` through `Source Data Fig. 6.xlsx`. Do not combine numbers from the old files with the final figures. The workbook contains no original Twitter/X post text or user identifiers. Some analyses require restricted post-level inputs that are not distributed here; see the repository [Data Availability](../DATA_AVAILABILITY.md) and the article Methods.
