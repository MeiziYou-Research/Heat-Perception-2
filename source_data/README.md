# Figure Source Data

[Source_Data_NCC_Figures.xlsx](Source_Data_NCC_Figures.xlsx) contains numerical data for main Figs. 2–6 and Extended Data Figs. 1–7, organised by figure and panel. Main Fig. 1 is conceptual and has no numerical Source Data sheet.

The workbook contains no original Twitter/X post text or user identifiers. See [Data Availability](../DATA_AVAILABILITY.md) for data-access information.
